Willkommen in Feedivo.

Waehle, wie du starten moechtest. Du kannst einen einzelnen Feed hinzufuegen, viele Feeds aus einer OPML-Datei uebernehmen oder Feedivo erst einmal leer oeffnen.

+
Feed hinzufuegen
Eine RSS-Adresse pruefen, optional einem Ordner zuweisen und importieren.
OP
OPML importieren
Viele Feeds und vorhandene Ordner aus einem anderen RSS-Reader uebernehmen.
..
Spaeter einrichten
Feedivo ohne Feeds oeffnen. Du kannst spaeter jederzeit neue Feeds hinzufuegen.

Gib die Adresse eines RSS- oder Atom-Feeds ein. Feedivo prueft die Quelle, zeigt den Status und laesst dich direkt einen Ordner zuweisen.
